# Known-good physics for 02_Ansys_Cylinder_50Hz, asserted by ../verify.py.
#
# These are not targets chosen by hand -- every one was MEASURED on a run that
# was independently checked against an exact or analytic value, and the
# tolerance is set by what the discretisation can actually hold, not by what
# happens to pass today. A tolerance loose enough to never fail is not a test.
#
#   key                value        tol      what sets the tolerance
# ---------------------------------------------------------------------------
# geometry, needed to compute the exact comparisons
a_mm                   1.5
length_mm              40.0
ngon                   40
sigma                  5.8e7
drive_voltage          1.0          1.0e-9
frequency              50.0

# R against the EXACT L/(sigma*A_poly) for the meshed polygon, not the circle.
# 1.4e-05 is what the solver reproducibly achieves; it held across the
# supervariable rewrite, the analysis reuse and both MUMPS backends, so a
# regression past 1e-04 means something real changed.
R_rel_error_max        1.0e-4

# L is not compared against an exact value -- there is no closed form for a
# finite box. It is pinned to the measured value so a CHANGE is caught.
L_nH                   22.5956      0.05

# Phi must be the z/L gradient. Worst-case over every wire node.
phi_vs_zL_worst_max    2.0e-3
phi_pointwise_rel_max  1.0e-2

# J(0)/J(a) against the Bessel ratio at a/delta = 0.1605. The exact value is
# 0.999959; we measure 0.999968. The tolerance is the gap plus headroom.
J_ratio_exact          0.999959
J_ratio_tol            5.0e-5

# ---------------------------------------------------------------------------
# THE PHASE OF J, which is the other half of the Bessel solution.
#
# J_z is a PHASOR. The magnitude check above is the familiar skin-effect
# picture; arg(J_z) is independent of it and, in practice, the tighter test. An
# error in the -j*omega*A term of E = -j*omega*A - grad Phi shows up in the
# phase before it shows up in |J|, and until this check existed that half of the
# solution was never compared to anything.
#
# Measured as arg( <J>core / <J>surf ) over the SAME bands as the magnitude
# ratio, with the complex field averaged and the argument taken afterwards --
# averaging the arguments instead is wrong wherever the phase spread inside a
# band is not small, which is exactly the high-frequency case. Referring both to
# the surface band cancels the drive's own phase, and J = sigma E is gauge
# independent, so this number is physical rather than a convention.
#
# At a/delta = 0.16 the lag is only 0.64 deg, and reproducing something that
# small is a real test of the reactive term rather than a trivial one: the
# magnitude ratio here is 0.99997, i.e. flat to five digits and nearly
# insensitive. We measure -0.62816 against the exact -0.63860, off by
# 0.0104 deg.
#
# Case 03 measures the IDENTICAL value, -0.62816, from a 1 A drive on the same
# mesh -- one more way the duality has to hold.
phase_lag_exact        -0.63860     # degrees
phase_lag_tol           0.03
