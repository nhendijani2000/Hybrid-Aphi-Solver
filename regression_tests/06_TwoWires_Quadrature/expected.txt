# Known-good physics for 06_TwoWires_Quadrature, asserted by ./verify_two_wires.py.
#
# WHAT THIS CASE IS FOR. It is the demonstration of the [postprocess] options --
# thirteen requests covering all three geometries, every display, phase_deg,
# colormap and data. See README.md for the tour and docs/USER_GUIDE.md Sec. 4
# for what the options mean.
#
# It is also, incidentally, the first case in the suite to use a port
# `phase_deg` at all. Nothing else would have caught that silently doing
# nothing.
#
# WHY TWO WIRES A QUARTER CYCLE APART. The options that are hardest to
# understand -- axial_ratio, peak against complex_magnitude, phase -- are all
# about ELLIPTICAL polarization, and a single conductor has none: B is purely
# azimuthal, the polarization ellipse collapses to a line, and all three go
# trivial. Case 05's median axial ratio is 9e-06. Two sources 90 degrees apart
# make B genuinely rotate, and the two-wire superposition says exactly where:
#
#     b/a = 0      on the line of centres, where both contributions point the
#                  same way so the sum stays linear however it is phased
#     b/a = 1      at (0, +/- d/2) -- PERFECTLY CIRCULAR, and there
#                  complex_magnitude overstates the true peak by the full
#                  sqrt(2) = 41 %, the equality case of the chain
#                  b <= |B(th)| <= a <= N <= sqrt(2) a
#
# THE MESH RESOLVES THE SKIN DEPTH, at about 4.2 elements per delta (median
# element 0.317 mm against delta = 1.32 mm). It did not always: at 0.6 mm, 2.2
# per delta, |J| in the core read 7.2 % high and the core-to-surface phase lag
# 7.4 degrees short -- consistently and in one direction, which is what
# too-coarse elements do to an exponential. Refining to 0.25 mm halved both, to
# +3.9 % and 4.2 degrees, which is first-order convergence in h.
#
# The refinement is spent INSIDE the conductors. A distance-to-the-surface field
# cannot do that -- distance is positive on both sides, so it refines a shell of
# air too, and that cost 660k elements of which more than half were air that
# varies on no such scale. Two gmsh Cylinder fields instead: 192k tets, ~20 s.
#
#   key                value        tol      what sets the tolerance
# ---------------------------------------------------------------------------
input                  two_wires.aphi

# geometry
wire_radius_mm         2.0
separation_mm          10.0
length_mm              20.0
sigma                  5.8e7
frequency              2500.0

# THE DRIVE. 1 A in each wire. The slab integral of Jz over 0.4L to 0.6L divided
# by the slab thickness is the current through it; 2 % covers the coarse mesh
# and the slab's own end effects.
drive_current          1.0          2.0e-2

# AND THE QUARTER CYCLE, which is the only thing in the suite that exercises a
# port phase_deg. Measured 90.014 degrees against the 90.0 asked for.
phase_difference_deg   90.0         1.0

# THE POLARIZATION ELLIPSE, which is what the case exists to show.
#
# At (0, +/- d/2) theory says b/a = 1 exactly; measured 0.9647. The floor is
# one-sided rather than a tolerance because the error can only go one way:
# discretisation rounds the ellipse off, it does not make a linear field
# circular.
axial_ratio_floor      0.90
#
# and there N/a must be its maximum, sqrt(2) = 1.41421. Measured 1.3895.
# This is the equality case of a <= N <= sqrt(2) a, so it ties the three
# magnitudes of docs/ComplexVectorPhasorConcept.md to a measurement rather than
# a derivation.
n_over_peak            1.4142136    0.05
#
# TWO DRAFTS OF THIS CHECK WERE WRONG, and the second failure is the instructive
# one.
#
# b/a is zero ON the line of centres -- both contributions point the same way
# there -- so the first draft asserted 0 for the median over a BAND around it.
# But b/a grows linearly away from the axis, so a band has no zero median.
#
# The second draft asserted the analytic value obtained by averaging over the
# window's AREA, 0.0722. That is the cells' median only if the cells are spread
# uniformly over the window, and they are not: refining the mesh moved the
# statistic from 0.0658 to 0.0509 while changing no physics. A test that moves
# when the mesh does, and the field does not, is measuring the mesh.
#
# It now evaluates the analytic AT EACH CELL'S OWN CENTROID and compares cell by
# cell, so both sides are sampled identically whatever the mesh does. Over the
# 1134 cells in the window the analytic median is 0.0616 and the measured 0.0509
# -- a residual of -0.0098.
axis_band_residual     0.0          0.03
