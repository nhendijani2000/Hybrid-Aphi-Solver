# Known-good physics for 05_Loop_1A_50Hz, asserted by ./verify_loop.py.
#
# WHAT THIS CASE ADDS THAT NOTHING ELSE IN THE SUITE HAS. Cases 01-04 are all a
# straight rod: SIMPLY CONNECTED, and the tree-cotree gauge has nothing hard to
# do on one. A closed ring is MULTIPLY CONNECTED. The current circulates with no
# terminal anywhere on the outer boundary, the cotree has to span the loop, and
# the only way to drive it is to CUT it. A gauge that wrongly killed the loop
# would show up here and in no other case.
#
# It is verified by ./verify_loop.py, not ../verify.py: the rod verifier finds
# the drive by differencing Phi between two end caps, and a ring has none.
#
#   key                value        tol      what sets the tolerance
# ---------------------------------------------------------------------------
input                  loop_50hz.aphi

# geometry. A 20-gon tube cross-section revolved about z.
loop_radius_mm         6.5
wire_radius_mm         0.8
ngon                   20
sigma                  5.8e7
frequency              50.0

# THE PORT'S OWN PROMISE: inject 1 A across the cut and 1 A must cross it.
drive_current          1.0          1.0e-3

# AND THE CHECK NO OTHER CASE CAN MAKE: the same 1 A must cross theta = pi/2,
# a plane with NOTHING prescribed on it. Measured 1.000183 against the cut's
# 0.999953 -- the current really does circulate the whole way round. This is
# the multiply-connected test, and it is the reason the case exists.
circulation_tol        1.0e-3

# R AGAINST THE EXACT VALUE FOR THIS SHAPE, computed in the verifier straight
# off the mesh. Note it is NOT 2 pi R/(sigma A): current flows azimuthally, so
# the path length is 2 pi rho and varies across the section, and the
# conductance is sigma * integral(dA / 2 pi rho) -- the current crowds toward
# the inner radius. Ignoring that is a 0.44 % error, an order above the
# solver's own. Measured 3.543745e-04 against 3.544922e-04 exact, -0.033 %.
R_rel_tol              2.0e-3

# ---------------------------------------------------------------------------
# L IS PINNED, NOT VALIDATED. STILL AN OPEN ITEM, BUT HALF OF IT IS SOLVED.
#
# Measured 19.3770 nH, against the published closed form for a circular loop of
# round wire, L = mu0 R [ln(8R/a) - 2 + 1/4] = 19.8027 nH: -2.15 %.
#
# IT WAS -4.02 %, AND THE FIRST HALF OF THE GAP WAS A MESH BUG. The ring used to
# be revolved as one +Pi sweep and one -Pi sweep. Both halves came out with the
# right volume -- 40.386 against 40.307 mm3 -- but the negative-angle half got
# 4557 tets against 11621, elements 23 % larger and two and a half times fewer.
# Half the conductor was quietly meshed coarse. Chaining two POSITIVE sweeps
# instead gives a count ratio of 0.988, and L moved 19.038 -> 19.377, closing
# 1.87 of the 4.02 points.
#
# That also retracts an earlier conclusion recorded here: "refining the tube
# moved L the wrong way, so resolution is NOT the cause". That test refined
# lc_ring globally while half the ring stayed relatively coarse, so it was
# measuring the wrong thing. Resolution IS part of it.
#
# WHAT IS STILL OPEN: the remaining -2.15 %. The domain is ruled out -- doubling
# it to 60 mm moved L by +0.2 %, and a dipole estimate puts the field energy
# beyond 30 mm at about 0.09 nH, 0.4 %. The remaining suspect is resolution of
# the AIR beyond one wire radius: a wire loop's magnetic energy is
# logarithmically distributed, roughly half of it between 1 and 10 wire radii
# from the surface, and that shell is meshed at 0.25 mm growing to 4 mm.
# Refining it to 0.25 mm out to 2.5 mm needs about 700k tets in the shell alone
# and does not fit in 32 GB, so it is recorded rather than resolved.
#
# EXTRACTING L HERE IS ILL-CONDITIONED, worth knowing before reading any of it.
# omega*L/R is 0.017: the reactance is 1.7 % of the resistance, so Im(Z) is a
# small difference on a large product. Dividing by the MEASURED current instead
# of the imposed 1 A lets that current's own 0.02 % imaginary part into the
# answer and moves L by 1.3 %, fifty times its own size. The verifier divides by
# the imposed current and says why.
#
# The tolerance below is therefore a REGRESSION GUARD on a number still 2 %
# from theory. Do not read a pass here as agreement with it.
L_nH                   19.3770      0.05
