# Known-good physics for 05_Loop_1A_50Hz, asserted by ./verify_loop.py.
#
# WHAT THIS CASE ADDS THAT NOTHING ELSE IN THE SUITE HAS. Cases 01-04 are all a
# straight rod: SIMPLY CONNECTED, and the tree-cotree gauge has nothing hard to
# do on one. A closed ring is MULTIPLY CONNECTED. The current circulates with no
# terminal anywhere on the outer boundary, the cotree has to span the loop, and
# the only way to drive it is to CUT it. A gauge that wrongly killed the loop
# would show up here and in no other case.
#
# It is verified by ./verify_loop.py, not ../verify.py: the rod verifier finds
# the drive by differencing Phi between two end caps, and a ring has none.
#
#   key                value        tol      what sets the tolerance
# ---------------------------------------------------------------------------
input                  loop_50hz.aphi

# geometry. A 20-gon tube cross-section revolved about z.
loop_radius_mm         6.5
wire_radius_mm         0.8
ngon                   20
sigma                  5.8e7
frequency              50.0

# THE PORT'S OWN PROMISE: inject 1 A across the cut and 1 A must cross it.
drive_current          1.0          1.0e-3

# AND THE CHECK NO OTHER CASE CAN MAKE: the same 1 A must cross theta = pi/2,
# a plane with NOTHING prescribed on it. Measured 1.000183 against the cut's
# 0.999953 -- the current really does circulate the whole way round. This is
# the multiply-connected test, and it is the reason the case exists.
circulation_tol        1.0e-3

# R AGAINST THE EXACT VALUE FOR THIS SHAPE, computed in the verifier straight
# off the mesh. Note it is NOT 2 pi R/(sigma A): current flows azimuthally, so
# the path length is 2 pi rho and varies across the section, and the
# conductance is sigma * integral(dA / 2 pi rho) -- the current crowds toward
# the inner radius. Ignoring that is a 0.44 % error, an order above the
# solver's own. Measured 3.543745e-04 against 3.544922e-04 exact, -0.033 %.
R_rel_tol              2.0e-3

# ---------------------------------------------------------------------------
# L IS PINNED, NOT VALIDATED. THIS IS AN OPEN ITEM.
#
# Measured 19.0378 nH. Two independent routes agree: the terminal voltage --
# the Phi jump across the cut -- gives 19.0378, and the field energy
# integral(|B|^2/mu)/|I|^2 gives 19.007. So it is what the solver produced,
# not a post-processing slip.
#
# EXTRACTING L HERE IS ILL-CONDITIONED, which is worth knowing before reading
# any of it. omega*L/R is 0.017: the reactance is 1.7 % of the resistance, so
# Im(Z) is a small difference on a large product. Dividing by the MEASURED
# current instead of the imposed 1 A lets that current's own 0.02 % imaginary
# part into the answer and moves L by 1.3 %, fifty times its own size. The
# verifier divides by the imposed current and says why.
#
# But it is 4.02 % BELOW the published closed form for a circular loop of round
# wire, L = mu0 R [ln(8R/a) - 2 + 1/4] = 19.8027 nH, and 3.75 % below the
# reference tool's 19.7484 nH. The reference agrees with the closed form to
# 0.27 %, so the disagreement is OURS.
#
# TWO EXPLANATIONS WERE TESTED AND BOTH FAILED:
#
#   * the finite domain. n x A = 0 at rho = 30 mm confines the return flux,
#     which lowers L. Doubling the domain to 60 mm moved L by +0.2 % only
#     (19.007 -> 19.046). A dipole estimate agrees: the field energy beyond
#     30 mm is worth about 0.09 nH, 0.4 %. NOT the cause.
#   * tube resolution. Refining lc_ring 0.25 -> 0.20 mm with M 20 -> 24 moved
#     L by -0.2 % (19.007 -> 18.972), the wrong way. NOT the cause.
#
# UNTESTED, and the remaining suspect: resolution of the air BEYOND one wire
# radius. The magnetic energy of a wire loop is logarithmically distributed --
# roughly half of it lies between 1 and 10 wire radii from the surface -- and
# that shell is meshed at 0.25 mm growing to 4 mm. Refining it to 0.25 mm out
# to 2.5 mm needs about 700k tets in the shell alone, which does not fit in
# 32 GB. So it is recorded rather than resolved.
#
# The tolerance below is therefore a REGRESSION GUARD on a number we do not yet
# claim is right. Do not read a pass here as agreement with theory.
L_nH                   19.0378      0.05
